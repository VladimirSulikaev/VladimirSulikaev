# Привет, я Вова 👋
Я аналитик данных с опытом в AdTech и In-app маркетинге.
Сейчас специализируюсь на построении аналитических систем с нуля, автоматизации отчётности и анализе продуктовых и маркетинговых метрик (Profit, Plan, Retention, Cohorts).

Я разрабатываю автоматизированные дашборды для различных команд digital-маркетинга и системы fraudalert, сокращаю ручную работу, отвечаю за отчётность и результаты для масштабирования или сокращения клиентов.

В свободное время играю на гитаре 🎸 и увлекаюсь автосимуляторами (Assetto Corsa, Dirt Rally) 🚘
